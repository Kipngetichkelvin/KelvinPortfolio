About Me

A student developer focused on practical, useful software

I am currently studying Computer Science and I enjoy turning what I learn in class into working software — web interfaces, small Python tools, and database-backed applications.

My interest in technology started with a simple question: how do the applications I use every day actually work? Studying Computer Science at the University of Embu has given me the chance to answer that question properly — from programming fundamentals in Python and C to databases, computer networking, and software engineering principles.

I learn best by building. I have worked on academic and personal projects that pushed me to design interfaces, structure data, and think about how a system should behave when real people use it. Along the way I have learned that a simple solution that works reliably is usually worth more than a complicated one that is hard to maintain.

My current goal is to gain real industry exposure through, internship, or job-shadowing opportunity, and to grow into an entry-level software development or IT role where I can contribute to a team and keep learning.

  • Building web interfaces with HTML5, CSS3 and JavaScript
  • Practising programming and problem-solving with Python and C
  • Learning how data is organised, stored and queried in databases
  • Applying software engineering fundamentals to small, complete projects
